Curso - Dev algum Dia

O que você vai aprender:

Aprenda a programar do zero, com uma imersão prática pensada para quem quer começar uma nova carreira. Preencha o formulário abaixo e receba todas as informações para participar.

Matérias:

  • Lógica de programação do absoluto zero
  • HTML, CSS e JavaScript na prática

Sobre o curso:

  • Duração: 8 semanas

  • Carga horária: 3 encontros por semana

Por que fazer o Dev algum dia

A área de tecnologia segue crescendo e abrindo portas para quem está começando agora. O Curso - Dev algum Dia foi criado para quem quer dar o primeiro passo real rumo a uma nova carreira — sem enrolação, direto para a prática, construindo projetos desde a primeira semana.

Perguntas Frequentes

Preciso saber programar antes de começar?
Não. O curso foi desenhado para quem nunca escreveu uma linha de código.
O curso é gratuito?
A parte inicial do curso SIM!
Vou receber certificado?
Sim, ao concluir todas as etapas do curso.
Quanto tempo por dia preciso dedicar?
Recomendamos de 1 a 2 horas por dia para acompanhar o ritmo das aulas e exercícios.
Preciso de algum equipamento específico?
Não. Um computador com acesso à internet já é suficiente para começar.
